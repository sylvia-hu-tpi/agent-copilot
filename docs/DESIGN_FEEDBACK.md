## A. 待 Design 回覆的一件事

### A-5 🟠 請補「結案」與「升級」兩個語氣標籤的配色

Design 已提出可以加一張語氣標籤色票 —— **請加，我們需要。**

我方的語氣是**五種**，畫布目前示範了三種：

| 語氣 | 畫布現況 | 我方實作現況 |
|---|---|---|
| 致歉 | `--warn` 字／`--warn-bg` 底／`--warn-bd` 框／`heart-handshake` | `--warn` 系（一致） |
| 說明 | `--navy-2`／`--navy-soft`／`--navy-soft-bd`／`info` | `--text-2`／`--surface-3`（**待對齊畫布**） |
| 挽留 | `--open`／`--open-bg`／`--open-bg`／`hand-heart` | `--warn` 系（**待對齊畫布**） |
| **結案** | **沒有示範卡** | `--text-2`／`--surface-3`（暫定） |
| **升級** | **沒有示範卡** | `--danger` 系（暫定） |

**希望的形式**：一張語氣標籤色票，五種一次看齊（不必是完整的建議卡，色塊＋標籤＋圖示即可）。

> **為什麼需要五種都定**：這五個值是我們的封閉集合，模型每次產生建議卡都會落在其中之一。
> 只要有一種沒有配色依據，那張卡在畫面上就是我們自己編的。
> ⚠️ 特別是「升級」—— 它與「致歉」的處置強度差很多，兩者若落在同一個色系，
> 客服掃一眼分不出來，而這正是語氣標籤存在的理由。

## B. 平台資料拿不到 —— 已對齊，請勿回退

> 這一段**沒有待辦**，列出來只是因為這些位置很容易在下一輪設計時被「補回去」，
> 而補回去的東西我們**拿不到資料**、只能再拿掉一次。

| 位置 | 現在的畫法（正確） | 為什麼不能放回原本的樣子 |
|---|---|---|
| 客服身分（頂列／presence／訊息泡泡） | **email**（`agent.lin@company.com`） | 平台沒有人名：登入回應沒有 `display_name`／`name`，團隊名冊 `display_name` 實測 12/12 全是 email。我們**不會**從 email 反推姓名——同名同姓、共用信箱、非英文名字都會產生錯的名字，而認錯同事正是撞單防護與 presence 最不能出錯的地方 |
| 左欄列項第二行 | 頻道 icon ＋ presence 標記 | 對話清單的 payload 沒有「最後一則訊息」的文字或發送者，要顯示就得對每一列各打一次訊息 API |
| 「N 則」數字 | 不帶總數的措辭 | 訊息 API 只回一頁 ＋ `hasMore`，沒有剩餘則數；組織清單也沒有進行中對話數 |
| 客戶輸入狀態 | **沒有這個元件** | 平台不提供。假造一個比沒有更糟——客服會為了等一個不存在的訊息而停手 |
| AI 訊息 meta | 只有時間（到秒） | 訊息 payload 沒有意圖與信心欄位；到秒是因為撞單判斷靠的正是秒級先後 |
| 未讀 | **圓點** | 我們的新訊息訊號在一次輪詢間隔內來幾則都只跳一次，數出來是「批次數」不是「則數」 |

## C. 實作仍與畫布不同的地方（告知，不必改畫布）

> 這些是我方**刻意**的選擇，列出來是為了讓下一輪核對時不會被當成「實作沒跟上」。

| # | 項目 | 畫布 | 實作 | 理由 |
|---|---|---|---|---|
| **C-10** | **字級** | 見畫布數值 | 全面加大約 **2.5px**，並由固定 px 改為 `rem` | 使用者分兩輪確認過的調整；`rem` 也讓瀏覽器／OS 的字級偏好能生效。**相對關係與 weight／letter-spacing 完全照畫布** |
| **C-11** | **情緒走勢圖寬度** | 128×34 靠右 | **整欄寬** | 要放最多 50 個評分點 ＋ 附件標記，128px 下每點只剩 2.5px |
| **C-12** | **頭像下拉裡的 email** | `text-overflow:ellipsis` 截斷 | 等寬字**允許換行、不截斷** | 那是要逐字核對「是不是我的帳號」的東西，而截斷正好蓋掉最能區分帳號的網域部分 |
| **C-5** | **服務模式說明** | 只描述模式本身 | 多一句「，包含在 iMBrace 官方介面工作的同事」 | 我們的鎖只在 AgentCopilot 內有效，這個邊界必須講清楚 |
| **C-6** | **拖曳把手的鍵盤操作** | 只畫滑鼠拖曳 | `role="separator"` ＋ 方向鍵／Home／End | 5px 的線對只用鍵盤的人等於不存在 |
